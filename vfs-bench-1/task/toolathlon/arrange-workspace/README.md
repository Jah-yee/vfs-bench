# Arrange workspace

Reorganize a flat workspace into a prescribed three-level directory tree —
`School`, `Work` and `Entertainment` with named subdirectories under each — and
file every existing document into the right place.

```bash
uv run python agent/run_agent.py toolathlon/arrange-workspace --tools vfs
uv run python agent/run_agent.py toolathlon/arrange-workspace --tools mcp
```
